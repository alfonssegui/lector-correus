# Lector de correus

Web app per al mòbil que llegeix en veu alta els correus d'Outlook de les carpetes «Correus Importants» i permet dictar-ne la resposta.

- Inici de sessió amb Microsoft (OAuth 2.0 + PKCE, sense servidor).
- Permisos de Microsoft Graph: `User.Read`, `Mail.Read`, `Mail.Send`.
- Els ID de l'aplicació i del directori es guarden només al dispositiu.
